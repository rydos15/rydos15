## Featured Project — Ginja Live Rig Monitor

**From Studio To Stage.**

Managing a studio and live-performance rig meant checking several applications and devices separately. I created Ginja to bring monitoring, MIDI routing, and troubleshooting into one Windows dashboard—helping me understand what my rig is doing and stay focused on performing.

My work combines application development, interface design, MIDI programming, and hardware integration. My custom Morningstar MC6 Pro setup includes two 3D-printed external foot controllers using resistor-ladder functionality for Ableton performance control.

Ginja includes a dashboard, detachable monitoring windows, configurable MIDI workflows, system-health tools, and an event monitor. I use it in my own performance workflow and continue developing it around real needs.

The project demonstrates how I approach problems: identify friction, build a usable solution, and extend it thoughtfully. Planned work includes deeper Ableton integration and additional device workflows.
